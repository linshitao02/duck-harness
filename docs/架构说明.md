# 架构

浏览器或桌面壳只负责会话列表、消息流和连接面板。业务在 FastAPI 里。

一次发送会把用户消息写入 MySQL，再进入工具循环：把当前会话里仍标记为“在上下文中”的消息、长期记忆、技能目录和任务交给模型。模型如果返回工具调用，后端就在本机执行，把结果存成 tool 消息，然后再问一次模型，直到它给出正文或达到步数上限。流式事件用 SSE 推回页面。

DeepSeek 和 Ollama 都走各自的 OpenAI 兼容接口。DeepSeek 用 `https://api.deepseek.com/chat/completions`，Ollama 用本机 `http://127.0.0.1:11434/v1/chat/completions`。

权限有三种。`auto` 直接执行。`plan` 只能用只读工具。`ask` 在修改类工具执行前等页面上的允许或拒绝。密钥文件和少数破坏性命令即使在自动模式下也会被拦住。

工作区默认是本仓库目录。终端是 PowerShell，文件工具可以读文本、Jupyter、PDF 和 Word，也可以生成 docx 附件。MCP 使用官方的 stdio 帧协议。
